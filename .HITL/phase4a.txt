==================================================
SUBJECT LAW
==================================================

360 Query consumes an ObjectContext VALUE.

It does NOT require publication into ObjectContextStore.

The global ObjectContextStore remains shell orientation/current-object state.

Do not publish nested objects merely to open Query.

Conceptually:

openQuery(subject: ObjectContext)

The invocation surface supplies the subject it already owns/builds.

For the Phase 04A Payroll Run pilot, that subject may come from the existing
published payroll_run context.

This design must remain capable of accepting settlementObject(...) later
without changing ObjectContextStore.

DO NOT IMPLEMENT FREE-FORM NATURAL LANGUAGE
==================================================

that pretends to be understood.

Conceptually:

  id
  mode
  label
  optional keywords
}

QueryProvider.run(
  object,
  suggestionId
)

Do not implement keyword-to-business-logic branching in the shared panel.

DOMAIN owns suggestion definitions and their execution.
