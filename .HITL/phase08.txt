# Mission

Repair the shared focus handoff contract for 360 Query.

The intended lifecycle is:

```text
invoke Ask about this
        ↓
open existing QueryPanel
        ↓
panel becomes visibly available
        ↓
focus enters the panel's intended first interactive control
        ↓
user operates query entirely by keyboard
        ↓
close / Escape
        ↓
focus returns to the element that invoked Ask about this
```

Do not change query semantics.

Do not change providers.

Do not add Payroll-specific focus code.

# 9. Focus timing

The fix must account for the fact that:

```text
openQuery()
```

updates state before the panel/input may exist in the DOM.

Do not rely on brittle arbitrary timing such as:

```text
setTimeout(..., 100)
```

unless the repository's existing primitive explicitly requires such scheduling and no deterministic lifecycle exists.

Prefer the component/open lifecycle that knows when the target is mounted.
