# 7. Required interaction law

While an Afenda modal is OPEN:

```text
keyboard focus MUST remain inside that modal's valid focus scope
```

until the user explicitly closes/dismisses it through a permitted mechanism.

Forward traversal:

```text
last valid focus target
→ Tab
→ first valid focus target
```

or the equivalent behaviour supplied by the actual Base UI primitive.

Reverse traversal:

```text
first valid focus target
→ Shift+Tab
→ last valid focus target
```

or equivalent primitive behaviour.

The exact first/last target depends on the surface.

Do not hard-code control names globally.

---

# 8. Guard law

A Base UI focus guard is infrastructure.

It must never become an observable endpoint that allows the user to continue into page content behind an active modal.

The acceptance criterion is NOT:

```text
focus guard never receives focus
```

because a sentinel may legitimately receive transient internal focus.

The actual law is:

```text
focus MUST NOT escape the active modal through the focus guard.
```

Measure final focus ownership after traversal.
